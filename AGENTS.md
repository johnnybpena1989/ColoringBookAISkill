# Coloring Book AI Skill repository instructions

When an assistant is asked to create a coloring book using this repository, read and execute [skills/coloring-book-creator/SKILL.md](skills/coloring-book-creator/SKILL.md). Follow its referenced production and KDP documents. Do not install packages, request API keys, call paid external image APIs, pretend art or PDFs were created, or publish without explicit authorization. This repository is a portable instruction set; use only available built-in capabilities.
