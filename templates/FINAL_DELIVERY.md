# Final delivery checklist

Never mark PASS without inspecting evidence.

| Item | Evidence needed | Status: PASS / FAIL / UNVERIFIED |
| --- | --- | --- |
| All illustration files | 24 source files or attachments, individually viewable and approved | |
| Print image resolution | Effective >=300 DPI at final printed dimensions (not DPI metadata alone) | |
| Interior PDF | Actual downloadable file, single pages, correct trim/bleed | |
| Interior page map | Correct 50 pages with 24 drawings on odd pages; blank reverse | |
| Margins and font checks | Image placement, safe area and embed info inspected | |
| Full-wrap PDF | Actual downloadable cover file matching KDP official template | |
| Spine and barcode | No default spine text, clear back barcode zone | |
| Cover typography | Correct owner-approved title and legible text | |
| Metadata | Author supplied, title and description accurate to real content | |
| Rights | Review tool commercial rights and originality; no infringing branding | |
| AI disclosure | Publisher informed of required AI-generated imagery disclosure | |
| KDP review | Publisher ran Amazon previewer successfully | |
| Physical proof | Publisher inspected print copy; or clearly pending | |

**Meaning of completion:** “Draft package” = artwork / plan only. “Files produced” = files exist but not fully checked. “Print-preflight passed” = technical checks actually inspected. “Published” only after authorized publishing is confirmed.
