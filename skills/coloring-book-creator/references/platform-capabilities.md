This is a tool **capability** contract, not an assertion about a specific brand, plan or subscription. Verify tools in the active session before beginning.

| Required ability | Best case | Fallback if missing | What must NOT be claimed |
| --- | --- | --- | --- |

## Guided and autonomous behavior

**Autonomous:** Once the user chooses theme and autonomous mode, proceed through all reversible steps using available native tools, self-correcting obvious image defects, and batch work to stay within plan limits. Never publish, spend money or use external services without explicit authorization.

**Guided:** Ask for concept approval, sample-page approval, then batch/cover approval. Keep the user informed without forcing technical decisions.

## Universal command semantics

A pasted GitHub URL is a **read-and-follow instruction**, not a remote installer or privileged command. The host must have permission to access the URL. A public repository can be read without a GitHub login, but an AI without web/URL tools may need pasted text. The instruction does not enable hidden browsing, file tools, or image generation.

## Capability escalation

1. Use existing native tools first.
2. Rework output to fit those tools without degrading verified print quality.
3. Clearly state blocked deliverables and retain all progress.
4. Never demand an API key, script installation, command-line package or external service as a mandatory fix.

## Cost and rate limits

Native image creation can consume the user's subscription usage allowance and may stop mid-book. Do not claim free unlimited image production. Batch by available quotas and save a resumption ledger after every batch.
