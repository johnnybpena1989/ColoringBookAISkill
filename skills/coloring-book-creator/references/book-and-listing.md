# Page architecture, cover production, and Amazon listing

## Default interior architecture

For 24 original pictures and 50 pages, use this literal map:
- Page 1 — title page (right-hand side)
- Page 2 — copyright and usage notes (left-hand side)
- Page 3 — artwork 01
- Page 4 — blank reverse
- Page 5 — artwork 02
- Page 6 — blank reverse
- Continue artwork 03–24 on pages 7,9,…,49; blanks on pages 8,10,…,50.

In left-to-right books, odd pages are right-hand pages and even pages left-hand pages. This is one picture per physical sheet front, not two images sharing one sheet.

No repeated scene or lazy auto-duplication to reach minimum page count. If different scene count is chosen, recalculate exact page map/page count and ensure the publisher agrees.

For front matter: typeset working title, subtitle if used, owner-approved imprint/author, copyright statement only if factually justified, publisher website only if provided, and age suitability without unsupported educational claims. Don't invent company names, copyright registrations or ISBN.

## Cover briefing

A cover must signal the customer, theme and inner art style within a glance. Produce a polished original full-color illustration (not monochrome inside-page art) showing a visually representative subset of the book's motifs. Leave quiet contrast area for typeset title and subtitle. Use separate editable text when supported; generated art often mangles lettering. Avoid asserting "50 coloring pages": the default contains 24 coloring illustrations across 50 physical pages.

For a wrap cover, obtain dimensions with official KDP calculator using:
- paperback
- black & white ink, white paper
- 8.5 x 11 in (or chosen trim)
- left-to-right
- actual final manuscript PDF page count

Construct left-to-right: back cover, spine, front cover; incorporate full external bleed. The spine thickness depends on actual page count and paper. Use official template overlays to place all title text within safety limits, and protect the barcode zone on back. No spine text for <=79 pages.

If the agent cannot build full wrap at exact dimensions, the work is incomplete; deliver front-cover design + precise spec and label this limitation. Never invent compliance verification.

## Customer-facing Amazon listing deliverable

Prepare:
1. Three truthful title options; select the approved one.
2. Subtitle only if it adds concrete buyer value and KDP metadata allows it.
3. Author or imprint field only after user confirmation.
4. A 100–180-word description emphasizing the experience, audience, subject variety, and actual illustration count/format. Avoid false claims like "award-winning" or "bestselling."
5. Seven **candidate** search-keyword phrases (not guaranteed searchable/approved). No competing author names or franchise trademarks.
6. Age/skill level, language, trim, binding, B&W interior, actual total page count and distinct illustration count.
7. Suggested categories based on topic; user confirms options displayed on live KDP.
8. A record of AI-generated art that must be disclosed in KDP.
9. Three sample-image concepts or verified preview images that match real interior pages.

Never fabricate research, customer reviews, market rank, cost, page count, ISBN, category availability, endorsements or royalties.

## Pre-publication gate

User retains final publishing control. Verify rights to images and text; run KDP previewer; check physical proof for clipping, thin lines and gray artifacts; check print cost and price through Amazon's calculator; inspect the live listing for title/content accuracy. No claims that the agent already published unless verified.
