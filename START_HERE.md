# One-message beginner setup — v2

Paste this into ChatGPT, Claude, Grok or another AI assistant that can read GitHub URLs:

> Read https://raw.githubusercontent.com/johnnybpena1989/ColoringBookAISkill/main/skills/coloring-book-creator/SKILL.md and follow it as my coloring book production workflow. Load its linked references as needed. Use your own native image and file tools; no API keys, installers, code or external services. Start by asking my theme and whether I want Autonomous or Guided mode. Create real downloadable book files wherever your tools allow; inspect and correct every page. Be explicit about anything your platform cannot actually produce.

Your assistant should ask what the book is about, then offer **Autonomous** (it makes most decisions) or **Guided** (you approve milestones). The workflow aims to create 24 original line-art drawings, a 50-page paperback interior, a cover and an Amazon listing draft.

It uses the image and document features **already present** in your AI assistant. If those tools are missing or usage limits stop production, it will save a project ledger and explain the next step; it must never pretend a PDF exists when it doesn't.

For updates or another book, paste the same instruction again. If the AI cannot open GitHub, manually paste [SKILL.md](skills/coloring-book-creator/SKILL.md).

Before selling a paperback, inspect the actual PDFs in KDP Print Previewer, review the AI-content disclosure questions and order a physical proof.
