# Start a coloring book

## For anyone using ChatGPT, Claude, Grok, or a similar AI

Copy the message below and paste it as a **new message** into your AI conversation. You do not need to download this repository.

> Open and read https://raw.githubusercontent.com/johnnybpena1989/ColoringBookAISkill/main/skills/coloring-book-creator/SKILL.md and follow it as my coloring book creator. Read any reference files you need from the same GitHub repository. Start a new coloring book project with me now, use your built-in image and document tools where available, and guide me through the entire process one decision at a time. Do not require programming, software installation, or an API key. Tell me explicitly if you cannot open the link or create a required file.

### What happens next

Your assistant first helps choose a topic. You can type something simple, like “cute woodland animals for children ages 6–9,” or ask it to suggest five ideas. Then it proposes 24 individual scenes, generates artwork with available native image tools, reviews the pages, and helps make the interior, cover and KDP listing.

The AI should keep decisions small and guide you through one at a time. If it lacks an image-generation or PDF-creation feature, it should say so and offer a realistic next step, **not** ask you for an API key or pretend the file is complete.

### Start another book or get updates

Paste the **same message** into a new session; it links to the current version on GitHub.

### When a platform cannot open GitHub

Open [SKILL.md](skills/coloring-book-creator/SKILL.md) yourself and paste its text into the conversation. The core instructions work independently; the optional reference files improve print/detail checks when the AI can load them.

### Important before publishing

The book is not ready to publish until you inspect the real files, use KDP's Print Previewer and cover template/calculator, and review a physical proof copy. You remain the publisher.
