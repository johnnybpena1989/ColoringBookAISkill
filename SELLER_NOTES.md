# Seller notes: what you are distributing

## Product

A **portable, GitHub-hosted Agent Skill**, not a desktop application, hosted generation API, print service, or publishing automation. A customer copies a single prompt; their assistant reads and follows the latest workflow. No account credentials, subscriptions to *your* infrastructure, installation or API key are necessary.

## Supported workflow, not guaranteed tool availability

- ChatGPT / Claude / Grok: copy the README prompt into a chat with URL/web access and an image generator. Capabilities differ by product, plan and mode.
- Other skill-aware coding agents: they can read the folder at skills/coloring-book-creator/SKILL.md as a standard Agent Skill.
- Agents unable to fetch URLs: customers can paste the skill document as text; there is no way for a GitHub link alone to bypass a platform's browsing restrictions.
- PDF creation and quality validation vary by platform; the skill never promises magic universal PDF tooling.

## Updating customers

Update files on the GitHub main branch. New customer sessions using the same link will request the updated instructions. It is *not* a background push or remotely installed plugin. When editing, protect customer trust with reviewed changes, version labels and consistent links.

## Selling a GitHub-hosted skill

This repository is public; anyone can read it without paying. Even with an all-rights-reserved notice, public URLs cannot enforce paid distribution. Sell legitimate value as onboarding, tailored book concepts, revisions, live consulting, premium private packs or maintenance; or choose gated hosting if source access must be restricted. Do not misrepresent built-in model usage costs or claim a private install when none exists.

## Buyer-facing scope statement

“Use your own AI assistant to create and prepare original print-on-demand coloring books. This workflow guides your AI through artwork creation, quality checks, covers and KDP preparation. Image generation and downloadable PDF capability depend on your AI plan; final files, copyright decisions and Amazon publication require review.”

No earnings or Amazon approval guaranteed.
